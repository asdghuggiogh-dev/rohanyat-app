# روحانيات — Android Native App (Kotlin + Jetpack Compose)

## الحالة الحقيقية لهذا المشروع — اقرأ هذا أولًا

تم كتابة **كل** الكود (~40 ملف Kotlin) لكل ميزات التطبيق: الرئيسية، تصفح، القرآن (قائمة + قارئ)،
الأذكار، الأدعية، المسبحة، Shorts، الفيديوهات، **مشغل فيديو حقيقي بـ Media3 ExoPlayer** مع تحكم كامل
(تشغيل/إيقاف، شريط تقدم، صوت، ملء شاشة، عدّاد مشاهدات حقيقي)، رفع فيديو/صور بمنتقي أندرويد الأصلي
(Photo Picker — يعمل بدون أي إذن Runtime على أندرويد 13+)، تخزين دائم حقيقي عبر Room + نسخ الملفات
لتخزين داخلي (بعكس نسخة الويب، الفيديو هنا **لا يختفي أبدًا** بعد إعادة فتح التطبيق)، الملف الشخصي
(صورة شخصية + غلاف قابلين للتغيير ودائمين)، البحث، الإعدادات.

**⚠️ هذا الكود لم يُجمَّع (Compile) ولم يُختبَر فعليًا** — لا يوجد لدي Android SDK ولا Gradle في بيئتي
لأشغّله. راجعت الكود يدويًا بعناية (توازن الأقواس، صحة الاستيرادات، منطق الدوال) وصلّحت عدة أخطاء
حقيقية وجدتها بهذه الطريقة، لكن يبقى احتمال وجود أخطاء تجميع (Compile Errors) صغيرة — خصوصًا
تعارضات إصدارات المكتبات (Compose BOM / Media3 / Room / Navigation) — لن تظهر إلا عند أول
Gradle Sync فعلي في Android Studio.

## كيف تبنيه

1. ثبّت [Android Studio](https://developer.android.com/studio) (أحدث إصدار مستقر).
2. افتح هذا المجلد (`RohaniyatAndroid/`) كمشروع (`File → Open`).
3. انتظر Gradle Sync الأول — هذا هو الاختبار الحقيقي الأول للكود.
4. إذا ظهرت أخطاء حمراء: أغلبها عادة تكون تعارض إصدار مكتبة بسيط، يصلحه Android Studio نفسه
   تلقائيًا بزر "Sync" أو "Update" الذي يظهر لك.
5. شغّله على جهاز حقيقي أو محاكي (`Run ▶`).

## إذا واجهت أخطاء تجميع (متوقع جدًا في أول محاولة)

أفضل طريقة لحلها فعليًا: افتح هذا المشروع مع **Claude Code** (أداة Anthropic الأخرى) وأعطه رسالة
الخطأ بالضبط من Android Studio — يقدر يقرأ الكود، يشغّل Gradle فعليًا، ويصلح الأخطاء تكرارًا حتى
ينجح البناء، وهذا شيء ما أقدر أسويه من هنا لأني بلا بيئة تجميع فعلية.

## نقاط تحتاج انتباهك قبل الإطلاق الفعلي

- **نصوص القرآن**: فقط 4 سور مُضمَّنة كنموذج (الفاتحة، الإخلاص، الفلق، الناس) — لا يوجد قاعدة بيانات
  قرآن كاملة مرخّصة مضمَّنة. اربطه بمصدر حقيقي (مثل ملف نصي من Tanzil.net) قبل النشر.
- **الأصوات/التلاوات**: لا توجد ملفات صوتية حقيقية مرفقة (نفس قيد الترخيص من نسخة الويب).
- **لا يوجد خادم/مستخدمون حقيقيون**: الفيديوهات المرفوعة تُخزَّن محليًا على هذا الجهاز فقط (بخلاف نسخة
  الويب، تبقى دائمة على هذا الجهاز تحديدًا)، لكن **لا يشوفها مستخدم آخر** لأنه لا يوجد خادم مركزي بعد.
  لتطبيق حقيقي متعدد المستخدمين، يحتاج Backend (خادم + قاعدة بيانات + تخزين سحابي) — مشروع منفصل.
- **الأيقونة**: أيقونة بسيطة بديلة (هلال ذهبي على خلفية زمردية)، استبدلها بتصميم احترافي حسب الحاجة.

## البنية

```
app/src/main/java/com/rohaniyat/app/
├── data/
│   ├── model/          نماذج البيانات (Video, Surah, Dua, Dhikr...)
│   ├── local/           Room (قاعدة بيانات محلية) + تخزين الملفات
│   └── repository/      طبقة البيانات (قرآن، أذكار، أدعية، فيديوهات)
├── viewmodel/            ViewModels لكل قسم
├── navigation/           Navigation Graph + شاشة تصفح
└── ui/
    ├── theme/            الألوان والخطوط (نفس هوية نسخة الويب: زمردي/ذهبي)
    ├── components/       عناصر مشتركة (شريط تنقل، بطاقة فيديو)
    └── screens/          كل شاشة في مجلدها الخاص
```
